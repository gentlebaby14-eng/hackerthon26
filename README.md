# RoomAI · 생활 패턴에 맞춘 가구 배치 시연

전 연령의 생활 패턴을 바탕으로 가구를 선택하고 배치를 비교하는 해커톤 프로젝트입니다.

| 폴더 | 내용 |
| --- | --- |
| `frontend/` | 제공된 HTML 디자인을 유지한 소개·조건 선택·가구 찾기·배치·동선·비교 화면 |
| `backend/` | Node.js API, 벽 기반 경로 계산 및 테스트 |
| `ai/` | CubiCasa5K 벽 정답 추출, U-Net 학습·평가·추론 코드 |

## 실행

Node.js 20 이상에서 `backend` 폴더의 `npm start`를 실행하고 http://127.0.0.1:3000 을 엽니다.

소개 → 가구 찾아보기 → 조건 선택 → 추천 후보 → 내 방에 배치 → 시뮬레이션 → 배치 비교 순서로 진행합니다. 디자인 기준은 사용자가 제공한 `roommate-redesign (5).html`입니다.

## 시연 시나리오

- **내 방 꾸미기:** 3300×2700mm 방에서 기존 슈퍼싱글 침대를 더블 침대로 바꾸고, 책상·옷장·화장대 접근 동선을 비교합니다. 르메르침대의 더블 침대 3개를 저장된 상품 정보로 표시합니다.
- **18개월 아기 방:** 3000×2400mm 방에서 장난감 수납장 3개와 놀이매트 3개를 저장된 상품 정보로 표시합니다. 작은 아기 캐릭터가 활동성에 따라 더 넓게 움직입니다. 수납장 문과 방문의 열림 범위가 겹치는 기존 배치에서 정지한 뒤 추천 배치에서는 끝까지 이동합니다.

조건 선택에서 방 용도, 찾는 가구, 현재 가구, 방 크기, 사용자 연령과 활동성을 직접 바꿀 수 있습니다. 평면도 이미지를 직접 올린 뒤 상품을 고릅니다. 여러 종류를 선택하면 가구 찾기에서 종류별 탭으로 각각 최대 3개를 볼 수 있습니다.

## 시연 범위

- 상품 추천의 Gemini 호출은 중단했습니다. 조건 선택 화면은 `frontend/index.html`에 저장된 9개 상품 중 선택한 가구 종류에 해당하는 카드만 보여줍니다. 상품명·표시 가격·대표 사진은 2026-11-11 네이버 판매 페이지에서 확인한 값이며, 사진 사본은 `frontend/assets/products/`에 있습니다. 상세 보기 버튼은 해당 판매 페이지로 이동합니다. 실시간 가격·재고는 판매처에서 확인해야 합니다.
- 카드의 가로·세로는 시뮬레이션용 예시 크기이며 판매처의 실측 제원이 아닙니다. 저장된 상품이 없는 가구 종류는 빈 결과를 표시합니다.
- 올린 평면도는 배치 화면에 나타납니다. 벽 전용 U-Net이 벽을 색칠하고, 가구를 드래그해 옮기거나 회전할 수 있습니다. 현관과 목적지를 찍으면 벽 마스크를 장애물로 사용해 동선을 계산합니다. 방 크기는 직접 입력해야 합니다. 현재 가중치는 합성 도면으로 학습했으므로 실제 아파트 도면의 벽 인식 결과를 확인해야 합니다.
- 생활 패턴과 활동성을 수정할 수 있습니다. 활동적일수록 예시 이동 경로와 탐색 범위가 커집니다.
- 시뮬레이션은 예시 방의 이동 범위와 선택 가구의 오른쪽 앞 모서리를 비교하며 실제 안전성을 판정하지 않습니다.
- 기존 U-Net 도면 분석 화면은 `/floorplan.html`에서 유지됩니다. 학습과 API 설명은 [ai/README.md](ai/README.md), [backend/README.md](backend/README.md)를 참고하세요.
- 모바일 발표용 벽 인식·방 선택 화면은 `/room-select.html`입니다. `예시 평면도 → AI로 구조 찾기 → 방 바닥 터치` 순서로 확인합니다.

검증: `backend` 폴더에서 `npm test`.
